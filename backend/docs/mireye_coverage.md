- Utilities & infrastructure

- Climate
- Soil

- Source
- Source URL
- Confidence

- Fetch timestamp
- TTL
- Status
- Partial failures

## Geographic Coverage
- USA-focused
- Mireye API geographic envelope

## Known Gaps
- Fields can return null/failed values
- Mireye does not provide arbitrary enterprise data
- Business-specific operational data must come from external systems
- Some capabilities require external data sources
